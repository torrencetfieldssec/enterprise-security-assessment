# Company Profile

## Organization Overview

Northstar Manufacturing is a mid-sized industrial electronics manufacturer created as part of the Enterprise Security Assessment & Compliance Program.

The purpose of this fictional organization is to provide a realistic enterprise environment in which cybersecurity technologies, governance processes, compliance activities, and security assessments can be performed.
